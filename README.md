# Localbeat (Beta)

> **Note:** This program is currently under development.

## What is Localbeat?

**Localbeat** is an open-source desktop application designed to play music in the background without ads or subscriptions.

The program runs entirely locally, without the need for an internet connection. Simply upload your MP3 files, create your playlists, and listen to your music without limits. Online features to download songs directly from the web are planned for the future (currently under evaluation).

## Programming Languages Used

* **Python**
* **PySide6** *(GUI)*
* **QSS**
